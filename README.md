# drug-response-transferability

Code and result files for the manuscript

> **Cross-assay concordance predicts the cross-dataset transferability of cancer drug-response models**
> Yen-Jung Chiu, Department of Biomedical Engineering, Chang Gung University (manuscript under review).

Models that predict cancer drug response from gene expression often lose accuracy
on an independent dataset. For each drug measured by two independent sensitivity
assays over the same cell lines (CTRP and GDSC2), this repository computes the
rank concordance of the two assays **from the labels alone, before any model is
trained**, and shows that it predicts how well models transfer across datasets.
The concordance is then used as a screen (which drugs to deploy) and as a training
filter (which cell lines to train on).

All randomness is seeded from base seed 42. In the reference/test analyses, drug *j*'s
external test set in split *s* is drawn with seed 42 + 1000*s* + *j* (*j* = the drug's
position in `drug_id_map.csv`), and the CTRP training/internal split and model fitting
use 42 + *s*; the single-split supporting analyses use 42. Every number and figure
in the paper is regenerated by the scripts below; the manuscript and supplement text
are not distributed here.

### Primary and supporting designs

The paper's **primary** analyses use a *reference/test design*: for every drug and
each of ten splits, an external test set of GDSC2 cell lines is drawn first, and the
CTRP–GDSC2 concordance is computed only on the remaining reference cell lines (never
on test cell lines), with the official GDSC2 release 8.5 fitted-curve AUC as the
GDSC2 response. These are the `*_rev` / `*independent*` scripts and the
`results/rev1_independent/`, `results/rev2_three_assay/` and
`results/rev3_consensus/` folders.

The remaining scripts implement the **original single-split design** (concordance on
all shared cell lines, mean-viability GDSC2 summary). They provide the supporting
analyses reported as such in the paper (correlates of concordance, reverse direction,
continuous regression, label/feature choices, biology, TCGA extension) and produce
input tables that the primary scripts reuse (the drug panel in
`per_drug_external.csv`, the drug list in `R3_consensus_per_drug.csv`, and the
reverse-direction results in `R6_bidirectional_per_drug.csv`).

## Repository layout

```
scripts/     analysis, figure and number-check scripts (paths set in scripts/config.py)
results/     result tables produced by the analysis scripts, as used in the paper
  rev1_independent/  reference/test validation, CTRP -> GDSC2 (primary)
  rev2_three_assay/  CTRP, GDSC2, PRISM leave-one-assay-out (primary)
  rev3_consensus/    label-combination training schemes (primary)
  rev1b_refsize_single/  single reference set of 20/50/100 lines per drug (primary)
checksums/   SHA-256 of the GDSC2 fitted dose-response file
run_all.sh   runs the complete pipeline in the correct order
data/        input data (not distributed; see below)
outputs/     figures written by the figure scripts
```

## Requirements

Python 3.11 with the package versions in `requirements.txt`:

```bash
pip install -r requirements.txt
```

## Input data

The raw inputs are public but are redistributed under their providers' terms, so
they are not included here. Download them and place them as follows (or point to
them with the environment variables in `scripts/config.py`):

| Path under `data/` | Content | Source |
|---|---|---|
| `depmap/OmicsExpressionTPMLogp1HumanProteinCodingGenes.csv` | CCLE log2(TPM+1) protein-coding expression | DepMap Public 25Q3, <https://depmap.org/portal/> |
| `depmap/Drug_sensitivity_AUC_(CTD^2)_subsetted.csv` | CTRP (CTD²) drug-sensitivity AUC | DepMap portal |
| `depmap/Drug_sensitivity_replicate-level_dose_(Sanger_GDSC2)_subsetted.csv` | GDSC2 replicate-level dose viabilities | DepMap portal / <https://www.cancerrxgene.org> |
| `depmap/Model.csv`, `depmap/Gene.csv` | DepMap cell-line and gene annotation | DepMap Public 25Q3 |
| `gdsc/GDSC2_fitted_dose_response_27Oct23.xlsx` | GDSC2 release 8.5 fitted dose-response table (official fitted-curve AUC); env `DRT_GDSC2_FITTED` | Genomics of Drug Sensitivity in Cancer, <https://www.cancerrxgene.org/downloads/bulk_download> (GDSC2 fitted dose response, release 8.5) |
| `prism/PRISM_secondary_AUC.csv` | PRISM Repurposing secondary screen, dose-response curve parameters (`secondary-screen-dose-response-curve-parameters.csv`, renamed) | DepMap PRISM Repurposing 19Q4 |
| `repurposing_hub/drug_catalog.parquet` | drug annotation with columns `drug, broad_id, moa, target, smiles, phase` | Broad Drug Repurposing Hub, <https://repo-hub.broadinstitute.org/repurposing> |
| `tcga/TCGA_RNAseq_logTPM_protein_coding.csv` | TCGA log-TPM protein-coding expression, Ensembl-indexed | Genomic Data Commons, <https://portal.gdc.cancer.gov/> |
| `tcga/tcga_paire.csv` | TCGA patient drug response (`Cancer, bcr_patient_barcode, drug_name, DrugBank ID, measure_of_response`) | TCGA clinical drug records via GDC |

The PRISM, drug-annotation and TCGA inputs are needed only for the three-assay,
biological-validation and patient-tumor analyses respectively. The GDSC2 fitted file
is needed by the primary (reference/test) analyses. Check that your copy is the one
used in the paper:

```bash
cd data/gdsc && sha256sum -c ../../checksums/SHA256SUMS
# f950a7027be265f8a7a74220a27fd18cbd368485349bd8c2048e88bb1cd07560  GDSC2_fitted_dose_response_27Oct23.xlsx
```

## Reproducing the paper

```bash
./run_all.sh
```

or run the steps individually in the order below. `run_external_validation.py`
must run first, because later steps (including the primary REV-1 and REV-3 scripts)
read its `results/per_drug_external.csv`; `run_consensus.py` and `run_robustness.py`
must run before `run_consensus_rev.py` and `make_figures_rev.py` respectively.

the train-only feature selection are in `rev_common.py`.

### Split and identifier files

* `results/rev1_independent/split_ids.csv.gz` — for every drug and split, the
  semicolon-separated DepMap `ModelID`s of the external GDSC2 **test** cell lines,
  the **reference** cell lines on which concordance was computed (fitted GDSC2
  summary), and the CTRP **train** and **internal** test cell lines.
* `results/rev1_independent/drug_id_map.csv`, `results/rev2_three_assay/drug_id_map.csv`,
  `results/rev3_consensus/drug_id_map.csv` — for each drug, all GDSC2 compound IDs
  sharing its name, the ID used (the one with most fitted cell lines), the number of
  fitted cell lines, and the CTRP column used. Vincristine has no fitted GDSC2 curve
  and is excluded from the primary analyses.

The figure and verification scripts need only the files in `results/`, so they run
without downloading any input data:

```bash
python scripts/verify_numbers_rev.py   # 69/69 checks
python scripts/make_figures_rev.py
```

`verify_numbers_rev.py` recomputes each headline number from `results/` and compares
it with the value reported in the paper.

The primary analysis scripts (`run_independent_validation.py`,
`run_three_assay_rev.py`, `run_consensus_rev.py`) train random forests and other
models for every drug and split with 20 parallel joblib workers (about 5–10 minutes
each on a 20-core machine).

If scikit-learn jobs exit unexpectedly, limit BLAS threads
(`OMP_NUM_THREADS=4 OPENBLAS_NUM_THREADS=4 MKL_NUM_THREADS=4`); `run_all.sh` sets
these by default.
